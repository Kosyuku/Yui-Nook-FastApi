### 2. Backend 框架与路由

**框架**: **FastAPI** + Uvicorn

**主入口** (`main.py`):
- 使用 `lifespan` 异步上下文管理初始化（tools, memory worker等）
- CORS 中间件配置
- 两个 router 挂载: `/api` (核心) 和 `/api` (扩展)

**核心路由** (`routes/__init__.py`):
- **POST `/api/chat`** - SSE 流式聊天接口
  ```python
  @api.post("/chat")
  async def chat(body: ChatRequest):
      # ChatRequest: session_id, content, agent_id?, model?
      # 返回 EventSourceResponse (SSE stream)
  ```
- **POST `/api/memories/add`** - 新增记忆 (agent_id可选)
- **GET `/api/memories/search`** - 搜索记忆
- **GET `/api/models`** - 列表可用模型
- **POST `/api/sessions`** - 创建会话

**扩展路由** (`routes/extra.py`):
- **POST `/api/todos`** - 待办事项
- **POST `/api/notes`** - 便签
- **POST `/api/diary`** - 日记
- **GET `/api/agents`** - 列表 AI agent
- **POST `/api/agent`** - 创建/更新 agent
- **Media APIs** - 上传/列表/删除媒体文件

### 3. Supabase Migration 格式

**位置**: `D:/YUI Nook/backend/scripts/`

**Migration 文件命名**:
```
20260429_01_agent_owner_first_batch.sql
20260430_01_activity_events.sql
20260501_01_activity_event_gate.sql
...
```

**格式示例** (时间戳 + 序号 + 描述):
```sql
-- 20260429_01_agent_owner_first_batch.sql
-- 说明：Agent ownership alignment

alter table messages
    add column if not exists agent_id text not null default 'default';

update messages
set agent_id = coalesce(nullif(sessions.agent_id, ''), 'default')
from sessions
where messages.session_id = sessions.id;

create index if not exists idx_messages_agent_session
    on messages(agent_id, session_id, created_at);
```

**核心表**:
- `agents` - AI agent 信息
- `sessions` - 对话会话
- `messages` - 对话消息
- `memories` - 用户记忆 (带向量搜索)
- `diary_entries`, `diary_notebooks` - 日记
- `todos`, `notes` - 待办/便签
- `media_items` - 媒体文件元数据

### 4. Tool Calling 处理

**位置**: `D:/YUI Nook/backend/tools/__init__.py`

**核心概念**:
- `TOOLS_SCHEMA` - 工具定义列表
- `TOOL_EXECUTORS` - Dict[工具名, 执行函数]
- `execute_tool_with_guard()` - 带守卫的工具执行

**内置 Tool 执行函数示例**:
```python
async def execute_get_current_time(args: dict) -> str:

async def execute_add_memory(args: dict) -> str:
    # args: content, category, tags, agent_id, visibility, ...
    # 调用 db.add_memory() 并返回 JSON

async def execute_search_memories(args: dict) -> str:
    # args: keyword, category, limit, agent_id
    # 语义搜索 or 关键词搜索

async def execute_list_diary_notebooks(args: dict) -> str:
    # 列表日记本，支持 agent_id 过滤
```

**在聊天中使用**:
- Claude 在 system prompt 中收到 `TOOLS_SCHEMA`
- 生成 tool use block 时，触发 `execute_tool_with_guard(tool_name, args)`
- 结果作为 assistant 消息返回给用户上下文

### 6. 前端 API 调用封装

**基础配置** (`apiBase.js`):
```javascript
export const apiBase =
  import.meta.env.VITE_API_BASE_URL ||
  (import.meta.env.PROD ? "https://api.somni-ref.top" : "");

export function apiUrl(path = "") {
  const value = String(path || "");
  if (/^https?:\/\//i.test(value)) return value;
  return `${apiBase}${value.startsWith("/") ? value : `/${value}`}`;
}
```

**使用模式** (原生 Fetch, 无外部 HTTP 库):
```javascript
// PerleApp.jsx 示例

  .then(r => r.json())

const uploadRes = await fetch(apiUrl('/api/perle/upload'), {
  method: 'POST',
  body: formData
});
```

### 7. 认证与 user_id 获取

**认证模型**: **Agent-ID 作为身份**（非 JWT）

**机制**:
- **`agent_id`** 是全局身份标识（如 `"azheng"`, `"ayan"`）
- 在请求中通过请求体或查询参数传递: `agent_id: Optional[str]`
- 系统维护一个默认 agent: `DEFAULT_AGENT_ID = "azheng"`

**在会话中**:
```python
# routes/__init__.py - ChatRequest
class ChatRequest(BaseModel):
    session_id: str
    content: str
    agent_id: Optional[str] = None  # 可选，未传时使用会话默认值
    model: Optional[str] = None

# 聊天处理
session = await db.get_session(body.session_id)
resolved_agent_id = str(session.get("agent_id") or "")
# 消息绑定到 agent_id
await db.add_message(body.session_id, "user", body.content, agent_id=resolved_agent_id)
```

**前端**:
```javascript
// App.jsx
const DEFAULT_AGENT_ID = "ayan";
// 聊天时: fetch(`/api/chat`, { agent_id: currentAgent.id, ... })
```

**无密码/Token**:
- 项目设计为单用户或信任环境（内网/本地）
- 支持 Supabase 行级安全，但暂未在前端实现认证流

### 总结表

| 组件 | 类型 | 位置 | 说明 |
|------|------|------|------|
| 后端框架 | FastAPI | `backend/main.py` | Uvicorn ASGI 服务器 |
| 核心路由 | Router | `backend/routes/__init__.py` | `/api/chat`, `/api/memories`, ... |
| 扩展路由 | Router | `backend/routes/extra.py` | Todos, Diary, Agents, Media |
| Tool 执行 | Module | `backend/tools/__init__.py` | Tool registry + executors |
| 数据库 | SQLite/Supabase | `backend/database.py` | 表定义 + CRUD |
| Migration | SQL | `backend/scripts/*.sql` | 增量schema更新 |
| 前端框架 | React | `frontend-react/src/App.jsx` | 主应用 + App 列表 |
| API 调用 | Fetch | `frontend-react/src/apiBase.js` | 无外部HTTP库 |
| 身份认证 | Agent-ID | 请求体/查询参数 | 非 JWT，基于 agent_id |

这个项目是一个**个人 AI 助手网关** + **多应用生态** 的设计，核心是 Agent-based 架构（每个 agent 独立记忆/对话），未来实现统一收件箱可扩展消息汇聚层。
